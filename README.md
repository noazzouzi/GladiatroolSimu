# Simulateur du Gladiatrool

Simulateur du mini-jeu **Gladiatrool** (DOFUS, Foire du Trool) : moteur de combat fidèle (carte, pics, archétypes,
vagues de Troolls, Mama Troollette) et planificateur qui cherche les meilleures actions pour une équipe de 4 personnages.

> Travail en cours : la phase de recherche (données du jeu, carte, mécaniques) est en cours dans `research/`.
